✨ What This Application Does

Modern laptops often have a mobile broadband card inside, the same kind of chip that lets a phone connect to a mobile network without Wi-Fi. The Dell DW5821e and DW5829e are two such cards, both built on the Snapdragon X20 chip family.

These cards support eSIM. An eSIM is simply a mobile plan that is downloaded into the card instead of being printed on a plastic chip you slide in. That is very convenient, but on a computer the tools for handling eSIM plans are often scattered or missing.

This project collects those missing pieces in one place: it manages your eSIM plans with a tool called lpac, opens a working internet session through the card using QMI or PPP, and adds the small system rules that make the card appear automatically every time you start your computer. It also shows how to keep several connections separate so they do not fight each other.

🧩 Main Features

  • eSIM plan management — add, list, switch and remove mobile plans stored inside the card, powered by lpac.
  • Ready-to-use data sessions — connect to the internet through the mobile card using QMI, the modern and fast method, or PPP, the older and very compatible method.
  • Automatic device setup — a set of udev rules makes the card recognised the moment it appears, so you do not have to type commands after every reboot.
  • Separate traffic lanes — per-uplink network namespaces let one connection handle everyday browsing while another handles a specific task, without mixing them up.
  • Recovery notes — clear written steps for when a card gets stuck, a session drops, or the modem seems to disappear.
  • Built for two models — instructions cover both the DW5821e eSIM and the DW5829e eSIM, including where the two behave differently.

📶 Managing Your eSIM Profiles

Think of an eSIM profile as a contact card for a mobile operator. It holds the details needed to join that operator's network. Your card can hold more than one, and you choose which one is active.

The application uses lpac behind the scenes to carry out the four things people actually need: adding a new profile from an activation code, showing a list of profiles already stored, turning one of them on, and removing one you no longer need.

Always add a profile first, check that it appears in the list, and only then switch to it. That order avoids most first-time confusion.

🔌 Connecting to Mobile Data

There are two ways the application can open an internet session through your mobile card. Both achieve the same result, so you only need the one that works best for your situation.

The first is QMI. It is the modern route and usually the fastest to set up. The second is PPP, an older and very widely supported route that often succeeds where newer methods struggle. If one does not connect, trying the other is a sensible next step.

Once a session is open, your computer behaves as if it were connected by cable or Wi-Fi, except the traffic travels over the mobile network instead.

🧭 Separate Traffic Lanes Explained

If your computer has more than one way to reach the internet, the traffic can get mixed together. The project includes a technique called per-uplink network namespaces, which is a fancy name for giving each connection its own private lane.

In practice this means one application can be told to use the mobile card while everything else keeps using your normal connection. The guide walks through setting this up step by step, and you can leave it alone entirely if you only ever use one connection.

🩺 Troubleshooting

  • The card is not detected. Restart the computer once and check again. The automatic device rules only take effect after a restart.
  • No internet even though the card is found. Switch between the QMI and PPP methods, and confirm the active eSIM profile belongs to a plan with data available.
  • A profile will not add. Re-check the activation code character by character. Codes are long, and one wrong character is the most common cause.
  • The session drops after a while. Note the time it happened and whether the laptop slept in between. Reopening the session usually restores service.
  • Two connections misbehave together. Follow the separate traffic lane section again and keep only one connection active while testing.

♻️ Recovery Notes

If something goes wrong, do not panic and do not reinstall your whole operating system. Almost every problem with these cards is solved by resetting the connection, not the computer.

Start by closing any open data session, then power the card down and up again from within the application. If that does not help, restart the computer and let the automatic device rules run from scratch.

The project includes written notes for the harder cases, including what to do when the card seems to vanish completely and how to bring it back without losing the eSIM profiles you already downloaded.
